Personal automation

A private assistant for the work that matters.

Hermes is a self-hosted personal AI assistant used to organize schedules, review documents, track tasks, and send reminders through Telegram.

Personal use · Not a public sign-up service

Calendar

Read calendar events to prepare schedules and notify the account owner of upcoming appointments and changes.

Documents

Read selected Google Docs, Sheets, and Drive files to extract relevant information and organize tasks.

Reminders

Run scheduled checks and deliver owner-requested notifications in Telegram.

How Google access works

Google account authorization is used solely for the owner's personal workflows. Integrations request read-only Google API permissions. This site itself has no Google sign-in form.

Learn how data is used in the Privacy Policy and review the Terms of Use.
